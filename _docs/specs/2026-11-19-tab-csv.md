# Tab CSV — chuyển lisp `xuat_csv_v5.0.1` sang C# (đặc tả)

Chốt qua phiên hỏi đáp ngày 2026-11-19. Lisp gốc: `laptrinhlisp\1. xuất fname ra csv\xuat_CSV_V4\xuat_csv_v5.0.1 ZWCAD.lsp`
(+ bản `AUTOCAD.lsp`), luật của lisp: `xuat_CSV_V4\.claude\rules\` (nhất là `05-csv-output.md`).

## Phạm vi
- Chuyển **cả B1** (Xuất thông tin tấm: phân tích hình học → MText) **và B2** (EXPORT: MText + F-name + dim → CSV) sang C#; lisp cũ thành lưu trữ.
- **2 giai đoạn**: GĐ1 = B2 + danh sách tấm + CSV mới bằng C#, nút B1 tạm gọi lisp cũ. GĐ2 = hình học B1 sang C#, xoá lisp.

## Vị trí
- Thư mục `07_CSV` (tab "CSV"), DLL riêng `CSVTOOL.dll` (`07_CSV/plugin/CsvTool.Plugin` + `CsvTool.Tests`), nạp như Guro/AI/Teams. ZWCAD 2026 + AutoCAD.
- `adminOnly` cho tới khi so khớp xong 3 đơn mẫu trên CAD thật.
- Lệnh `CSV` = mở bảng OHTA, chuyển sang tab CSV. Không còn DCL.

## Giao diện (một tab, không palette riêng)
1. Thanh nút: `Xuất thông tin tấm` (B1) · `EXPORT` (B2) · radio Chế độ tính (0 bình thường / 1 chỉ gia công / 2 vật liệu khách) · ⚙ cài đặt (sắp xếp L→R / Top→Bottom / Alphabet, layer khung / dim / tapu, ưu tiên layer mặc định, bước spline, dung sai khe hở).
2. **Danh sách tấm** (như DST nhưng nhiều thông tin hơn): sửa 2 chiều — ô thông tin tấm ghi vào MText, ô N/Q/M/T ghi vào F-name. CSV chỉ ghi khi bấm EXPORT. Cột lỗi + lọc "chỉ tấm lỗi". Bấm dòng → zoom tới tấm; bấm lỗi → zoom + **vòng tròn đỏ tạm thời** (kiểu `_ZwCloseLine`, không nằm trong bản vẽ).
3. Dòng trạng thái: đường dẫn 2 file vừa ghi + nút mở.
- Bỏ `-ERROR.dwg` / tự so sánh.

## Dữ liệu
- MText thông tin tấm giữ **nguyên định dạng** (12 dòng cố định + các dòng đường bẻ) — bản vẽ cũ vẫn xuất được.
- EXPORT ghi **2 file một lượt**, có lỗi ở bất kỳ tấm nào thì **không ghi file nào**:
  - `<thư mục dwg>\<đơn>.csv` — UTF-8 BOM, CRLF, tiêu đề đúng chữ: `エクスポート用,数量,材質,板厚,noと安全,曲げ,X,Y,,単価`.
    Cột: N= · Q= · M= (giữ nguyên chuỗi) · T= · `<đơn>-` · mã 曲げ · X · Y (dim tổng, X ≥ Y) · trống · 単価 trống.
  - `<thư mục dwg>\data\<đơn>-data.csv` — file 35 cột cũ, **giữ nguyên từng byte**.
- Mã `曲げ` (chỉ dựa vào dòng "Các loại gia công"): `m`/`m(pitchi)`→`m`, `k`→`k`, `s`→`s`, `t`→`t`, `r1`/`r2`→`r`; ≥ 2 loại → `*`; trống → trống.
- Mã đơn: tên file bỏ đuôi và hậu tố `-a`/`-s` (không phân biệt hoa thường).
- Không phối hợp với GRO (hai quy trình không chạy trên cùng bản vẽ).
- Cài đặt: `HKCU\Software\OFT_Lisp\CSV`; chưa có thì đọc 1 lần các khoá cũ ở `HKCU\Software\Autodesk`.
