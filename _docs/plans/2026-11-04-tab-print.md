# Tab PRINT (lệnh OI v2.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm tab PRINT vào OHTA TOOL: in khung `Khung_IN` / vùng quét / extents ra PDF bằng C#, có cấu hình in đặt tên và quy tắc "ưu tiên bản vẽ".

**Architecture:** Logic thuần (sắp khung, đặt tên PDF, giải quyết thông số + cảnh báo, mã hoá cài đặt) nằm ở `_system/OhtaTool.Plugin/Core/Print*.cs`, test được không cần CAD. Phần CAD (`Services/CadPrintService.cs`) đọc page setup, gom khung, in từng trang bằng `PlotEngine` ra PDF tạm; `Services/PdfMerger.cs` gộp bằng PdfSharp. Tab chỉ ghi yêu cầu in vào `PrintRunner.Pending` rồi gửi lệnh nội bộ `OIIN`, để việc pick điểm và in luôn chạy trong ngữ cảnh lệnh (document đã khoá, `BACKGROUNDPLOT` = 0).

**Tech Stack:** C# (net48 cho ZWCAD 2026, net10.0-windows cho AutoCAD 2027), WPF, `PlotEngine`/`PlotSettingsValidator`, PDFsharp 6.2.4 (MIT), registry HKCU.

**Spec:** [_docs/plans/2026-11-04-tab-print-spec.md](2026-11-04-tab-print-spec.md)

- `Core/` không tham chiếu CAD, WPF hay PdfSharp (test project biên dịch thẳng `Core/*.cs`).
- File `.cs`, `.json`, `.md` UTF-8. Không thêm `.lsp` mới.
- `module.json`: `id` `print`, `tabTitle` `PRINT`, `title` `OI`, `version` `2.0`, `accentColor` `#2E7D32`, `order` `40`.
- Registry: `HKCU\Software\OFT_Lisp\IN`, giá trị `defaults`, `profiles`, `last_profile` (chuỗi).
- Layer cảnh báo tắt in: tên bắt đầu `CANH_BAO_` (không phân biệt hoa thường) và `GRO_XEP_NHOM`.

## Review Focus

1. Cấu hình có tên mà cả thông số của cấu hình, của bản vẽ lẫn mặc định ⚙ đều không có trên máy (vd máy không cài `DWG To PDF.pc3`) → không được crash; lấy mục đầu tiên máy có và cảnh báo — test `Resolve_AllMissing_FallsBackToFirstAvailable` (Task 2).

3. Nhiều khung có Y lệch nhau dưới 1 mm theo chuỗi (0; 0.8; 1.6) → sắp xếp không được ném "IComparer inconsistent" và phải xác định — test `SortFrames_ChainedTolerance_Deterministic` (Task 1).
4. Tên bản vẽ như `DATA.dwg`, `ABC-s.dwg`, `X-SA.dwg` → chỉ bỏ đúng `-S`/`-A` cuối — test `PdfBaseName_Cases` (Task 1).

var byY = frames.OrderByDescending(r => r.Ymax).ThenBy(r => r.Xmin).ToList();
var result = new List<FrameRect>();
for (int i = 0; i < byY.Count; ) {
    double top = byY[i].Ymax; int j = i;
    while (j < byY.Count && top - byY[j].Ymax <= YTolerance) j++;
    result.AddRange(byY.GetRange(i, j - i).OrderBy(r => r.Xmin));
    i = j;
}
return result;

1. Thứ tự nguồn: profile (nếu có) → drawing → defaults → mục đầu tiên của catalog.
2. Lấy nguồn đầu tiên có giá trị **và** máy có.
3. Nếu một nguồn đứng trước có giá trị nhưng máy không có → thêm cảnh báo đúng một dòng cho trường đó: `Không có {giá trị bỏ qua đầu tiên} → đang dùng {giá trị dùng} ({nhãn})`, nhãn ∈ `theo bản vẽ` / `mặc định` / `có sẵn trên máy`.
4. `Lineweights`, `Merge`, `OpenAfter`: profile → drawing (chỉ `Lineweights`) → defaults → `true`; không cảnh báo.
5. Catalog rỗng cho một trường → giá trị `""` + cảnh báo `Không có máy in / khổ giấy / bảng ctb nào trên máy`.
